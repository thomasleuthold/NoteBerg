## Development History

### Major Pivot: Web → Tauri
- **Reason**: Eliminate CORS issues with Nextcloud sync
- **When**: After attempting CORS proxy and same-domain hosting
- **Impact**: Desktop + Android support, native HTTP, no browser limitations

### Sync Evolution
1. Started with WebDAV + credentials
2. Attempted CouchDB (reverted)
3. Implemented Nextcloud Login Flow v2 + WebDAV
4. Removed CORS proxy after Tauri switch

## Data Schema (IndexedDB)

```javascript
notebooks: { id, name, color, createdAt, updatedAt }
notes: { id, notebookId, name, content, strokes, createdAt, updatedAt }
```

## Nextcloud Sync Flow

1. **Login Flow v2:**
   - POST `/index.php/login/v2` → poll token + login URL
   - Open URL via `openUrl()` (opener plugin)
   - Display URL in input for manual copy (Android fallback)
   - Poll every 5s until user approves
   - Store appPassword + loginName in localStorage

2. **WebDAV Ops:**
   - MKCOL, PUT, GET, PROPFIND, DELETE
   - Auth: Basic `username:appPassword`
   - Path: `/oneJournal/{notebook|note}_{id}.json`

## Tauri Plugins

```javascript
import { fetch } from '@tauri-apps/plugin-http';
import { openUrl } from '@tauri-apps/plugin-opener';
```

**Why opener plugin:**
- shell:open doesn't work on Android
- opener uses Android Intent system
- Still provide manual copy fallback

## Android Build

**Requirements:**
- Java 17
- Android SDK + NDK + Command-line Tools
- Environment: ANDROID_HOME, NDK_HOME
- First build: 15-30 minutes (Rust compilation)

**Keystore:**
- Path: Use forward slashes on Windows
- Properties: storePassword, keyPassword, keyAlias, storeFile
- Output: `src-tauri/gen/android/app/build/outputs/`

## Drawing System

**Strokes:**
```javascript
{x, y, pressure, timestamp}
```

**Modes:**
1. Draw (freehand)
2. Erase (intersection-based)
3. Text (overlay)

**Auto-switching:**
- Detect drawing → draw mode
- Click text → text mode

**API:** PointerEvent (stylus/touch/mouse + pressure)

## Known Issues

1. Android shell:open fails → using opener plugin
2. Login URL may not auto-open on Android → manual copy needed
3. First Android build very slow (expected)

## Code Patterns

```javascript
  'Content-Type': 'application/x-www-form-urlencoded',

  'User-Agent': 'oneJournal/1.0'

```

## Security

- HTTPS enforced in production
- Cleartext only in debug builds
- LocalStorage for credentials
