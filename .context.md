# oneJournal - Project Context

> Quick reference for developers and AI assistants working on this project

## Project Overview

**oneJournal** is a cross-platform note-taking application supporting handwritten notes, text, and drawings with WebDAV sync. Built as a self-contained HTML/CSS/JavaScript PWA.

**Key Philosophy:** Simple, offline-first, user-owned data, e-paper friendly.

## Technology Stack

- **Frontend:** Vanilla HTML5/CSS3/JavaScript (ES6+) - No frameworks
- **Build:** Vite (dev server + bundler to single HTML file)
- **Storage:** IndexedDB (via `idb` library)
- **Sync:** WebDAV protocol (Nextcloud compatible)
- **Task Runner:** Just (cross-platform command runner)
- **Code Quality:** ESLint + Prettier

## Core Architecture Decisions

### 1. Single HTML File Distribution

- Vite bundles everything into one `dist/index.html` (~10KB initial)
- Easy to distribute, host, or run locally
- Can still be installed as PWA

### 2. All Notes Support Mixed Content

- **No note "types"** - every note supports text + handwriting + drawing simultaneously
- Schema: `textContent` (string) + `strokes` (array) in same note
- Simpler UX: users don't choose type upfront

### 3. Infinite Scrolling Canvas

- Vertical scrolling notebook pages (up to tens of A4 pages)
- Virtual rendering: only visible pages + buffer
- Page size: A4 dimensions (794x1123px @ 96dpi)
- Strokes include page number: `{x, y, pressure, timestamp, page}`

### 4. Three-Theme System

- **Light:** Default clean interface
- **Dark:** Low-light optimized
- **High Contrast (E-Paper):** Pure B&W, no animations, e-ink optimized

### 5. Component Architecture

- **Template Functions:** Simple functions returning HTML strings
- No Web Components or frameworks - just functions
- Example: `noteCard({title, preview}) => HTML string`

## Database Schema (IndexedDB)

```javascript
{
  notebooks: {
    id: UUID,
    title: string,
    description: string,
    color: string,
    created: timestamp,
    modified: timestamp,
    synced: boolean,
    deleted: boolean
  },
  notes: {
    id: UUID,
    notebookId: UUID | null,  // null = quick note
    title: string,
    textContent: string,       // Rich text
    strokes: array,            // [{points: [{x,y,pressure,timestamp,page}], color, width, tool}]
    canvasData: blob,          // Preview snapshot
    created: timestamp,
    modified: timestamp,
    synced: boolean,
    deleted: boolean,
    tags: array
  },
  settings: {
    key: string,
    value: any
  },
  syncQueue: {
    id: auto-increment,
    itemId: UUID,
    itemType: 'note' | 'notebook',
    operation: 'create' | 'update' | 'delete',
    timestamp: timestamp
  }
}
```

## Key Implementation Notes

### Canvas & Stylus

- Use **Pointer Events API** (not touch events)
- Capture `pointerType` to detect stylus vs touch vs mouse
- Read `pressure` property for pressure sensitivity
- CSS: `touch-action: none` on canvas to prevent scrolling while drawing

### Infinite Canvas

- Container with `overflow-y: scroll`
- Canvas height = pages × pageHeight
- Render only visible pages + 1 page buffer above/below
- Track `currentPage` based on scroll position
- Store strokes with page number for efficient retrieval

### Theme System

- CSS custom properties for all colors
- Load theme CSS dynamically via `<link>`
- E-paper mode: `prefers-reduced-motion` + disable animations
- Persist theme in IndexedDB settings: `{key: 'theme', value: 'dark'}`

### WebDAV Sync

- Use `webdav` npm package
- Store credentials in IndexedDB (encrypted if possible)
- Sync queue for offline changes
- Conflict resolution: last-write-wins (can add manual merge later)
- File format: `{noteId}.json` with both textContent and strokes

## Design Principles

1. **Offline-first:** Everything works without network
2. **No lock-in:** WebDAV = user owns data
3. **Accessibility:** E-paper theme for outdoor reading
4. **Performance:** Virtual scrolling, lazy loading
5. **Simplicity:** No unnecessary abstractions
6. **Progressive:** Start simple, enhance as needed

## Common Patterns

### Template Component Example

```javascript
// components/noteCard.js
export function noteCard({ id, title, textContent, strokes, modified }) {
  const hasText = textContent && textContent.length > 0;
  const hasStrokes = strokes && strokes.length > 0;
  const preview = textContent?.substring(0, 100) || 'No content';

  return `
    <div class="note-card" data-id="${id}">
      <div class="note-card-title">${title}</div>
      <div class="note-card-preview">${preview}</div>
      <div class="note-card-meta">
        <span>${new Date(modified).toLocaleDateString()}</span>
        <div class="note-card-indicators">
          ${hasText ? '<span class="note-indicator has-text"></span>' : ''}
          ${hasStrokes ? '<span class="note-indicator has-strokes"></span>' : ''}
        </div>
      </div>
    </div>
  `;
}
```

### IndexedDB Pattern

```javascript
// modules/storage.js using idb
import { openDB } from 'idb';

const db = await openDB('oneJournal', 1, {
  upgrade(db) {
    db.createObjectStore('notes', { keyPath: 'id' });
    db.createObjectStore('notebooks', { keyPath: 'id' });
    db.createObjectStore('settings', { keyPath: 'key' });
  },
});

export async function saveNote(note) {
  return db.put('notes', note);
}
```

## Browser Support

- **Target:** Modern browsers (Chrome 90+, Firefox 88+, Safari 14+, Edge 90+)
- **Mobile:** iOS Safari 14+, Android Chrome 90+
- **Features used:**
  - ES6+ modules
  - Pointer Events API
  - IndexedDB
  - Canvas 2D
  - CSS Grid/Flexbox
  - CSS Custom Properties

## Performance Targets

- Initial load: < 1 second
- Note switching: < 100ms
- Canvas rendering: 60fps
- Supports: 1000+ notes, 100+ strokes per page
- Build size: < 500KB (single HTML)

## Security Considerations

- WebDAV credentials stored in IndexedDB (consider encryption)
- No eval() or unsafe HTML injection
- CSP headers when hosted
- HTTPS required for PWA features
