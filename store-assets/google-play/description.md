## Full description

NoteBerg is a privacy-first note-taking app for handwriting, rich text,
and PDF annotation — with optional Nextcloud sync.

YOUR DATA STAYS YOURS
All notes are stored locally on your device. Sync is optional and only
works with a Nextcloud server you control. We have no servers, no accounts,
no cloud of our own.

HANDWRITING & DRAWING
• Write naturally with a stylus — pressure sensitivity supported
• Pen and marker/highlighter tools with customizable colors
• Lasso selection — move, resize, rotate and copy handwritten strokes
• Unlimited undo/redo

RICH TEXT EDITING
• WYSIWYG text editor with formatting, tables, colors and font sizes
• Task checkboxes inline with notes

PDF & IMAGES
• Import PDFs and annotate them with pen and text
• Insert photos directly from your camera or gallery
• Perspective correction for photographed documents
• Export notes as PDF with A4 pagination

ORGANIZATION
• Notebooks for hierarchical organization
• Note overview with thumbnail previews
• Full-text search across all notes
• Task marker overview across all notebooks
• Recycle bin with soft delete

SYNC & SECURITY
• Nextcloud sync via WebDAV (optional)
• Offline-first — works without any internet connection
• Optional end-to-end encryption with AES-256-GCM
• Conflict resolution for concurrent edits

OPEN SOURCE
NoteBerg is fully open source (MIT license). You can review the source
code on GitHub: https://github.com/thomasleuthold/NoteBerg

NoteBerg is currently in beta. Feedback and bug reports are welcome
via GitHub Issues.
